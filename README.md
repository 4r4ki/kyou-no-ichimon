# きょうの一問

毎日「ふつう」と「難問」の2問、むずかしいけど面白い問題が届く、スマホ向けの学習アプリです（中学生〜大人向け）。

## できること

- 毎日2問：「ふつう」（★1〜3）と「難問」（★4〜5）。タブで切りかえて、どちらにも挑戦できます
- 問題は約1300問：手作りの問題が約250問、プログラムで作った問題が約1000問
- ジャンルは5つ：算数・数／論理／図形・ひらめき／ことば・なぞなぞ／季節・きょうの日
- 特別な日（円周率の日、七夕、ハロウィン、大みそか など）には、その日にちなんだ問題が出ます
- 日曜日の「ふつう」は「きょうの日付の4つの数字で10を作れ」（作れる日だけ）
- 答えは選択式か入力式。何回でも挑戦でき、段階的なヒントと「降参」ボタンがあります
- 正解すると解説が出て、結果をシェアできます
- 記録：連続正解日数（その日にどちらか1問正解すれば続く）、正解数、難問クリア数。使っている端末のブラウザの中にだけ保存されます
- 直近7日の問題は、あとから解くこともできます（連続日数には数えません）
- ライト／ダークテーマ

## 使い方

`index.html` をブラウザで開くだけで使えます。GitHub Pages で公開すると、スマホからURLで遊べます。

## ファイル

| ファイル | 中身 |
|---|---|
| `index.html` | 画面 |
| `problems.js` | 手作りの問題 |
| `generated.js` | 自動で作った問題（`tools/generate.mjs` が書き出す。手で書きかえない） |
| `core.js` | 出題スケジュールと答え合わせ |
| `tools/generate.mjs` | 自動で問題を作るプログラム（覆面算、虫食い算、10や24を作る、うそつき問題、順位当て、最短経路など21種類。答えはすべてプログラムで計算） |
| `tools/check.mjs` | 全問題の検査（正解が本当に正解になるか、2年分の出題スケジュールなど） |

## 問題の追加方法

手作りの問題は `problems.js` の `PROBLEMS` に追加します（書き方はファイルの先頭に説明があります）。`level` が4以上の問題は「難問」、3以下は「ふつう」として出題されます。

追加したら、検査を実行してください。

```sh
node tools/check.mjs
```

自動で作る問題を作り直すときは、次を実行します（乱数の種が固定なので、同じ内容なら同じ問題ができます）。

```sh
node tools/generate.mjs
node tools/check.mjs
```

一度解いた（さわった）日の問題は記録に問題IDが残るので、問題を追加しても入れかわりません。自動生成の問題のIDは中身から決まるので、生成プログラムを変えるとIDが変わることがあります。そのときは記録に残ったIDが見つからず、その日はいまのスケジュールの問題が出ます。
