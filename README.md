# きょうの一問

1日1問、むずかしいけど面白い問題が届く、スマホ向けの学習アプリです（中学生〜大人向け）。

## できること

- 毎日ちがう問題が1問出ます（日付が変わると次の問題）
- ジャンルは5つ：算数・数／論理／図形・ひらめき／ことば・なぞなぞ／季節・きょうの日
- 特別な日（円周率の日、七夕、ハロウィン、大みそか など）には、その日にちなんだ問題
- 日曜日は「きょうの日付の4つの数字で10を作れ」（作れる日だけ）
- 答えは選択式か入力式。何回でも挑戦でき、段階的なヒントと「降参」ボタンつき
- 正解すると解説を表示。結果をシェアできます
- 連続正解日数・正解数などの記録（使っている端末のブラウザの中にだけ保存）
- 直近7日の問題は、あとから解くこともできます（連続日数には数えません）
- ライト／ダークテーマ

## 使い方

`index.html` をブラウザで開くだけで使えます。GitHub Pages などで公開すると、スマホからURLで遊べます。

## 問題の追加方法

`index.html` の `PROBLEMS` に追加します。

- `genre`：`math` / `logic` / `shape` / `word` / `season`
- `type: 'choice'`：`choices` と、正解の番号 `answer`（0 から数える）
- `type: 'input'`：受け付ける答えの配列 `answer`（数は数として比べるので `0.99` と `99/100` も同じ）、単位 `unit`
- `date: 'MM-DD'`：その日だけに出る問題／`month`：その月の15日（2問目は5日、3問目は25日）に出る季節の問題
- どちらもない問題は、ふだんの日に順番を混ぜて出題されます
